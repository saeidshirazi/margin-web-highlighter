## GitHub release alerts

Open **Settings & backups → Extension updates** and enable **Check GitHub for updates**. Margin shows a toolbar badge and a release link when it finds a newer version. You can also select **Check now**.

Install this version once to start receiving alerts. Future GitHub packages still use the manual update process. The Firefox XPI is unsigned and loads as a temporary add-on.

[Install and update guide](https://github.com/saeidshirazi/margin-web-highlighter/blob/main/docs/INSTALL.md)
