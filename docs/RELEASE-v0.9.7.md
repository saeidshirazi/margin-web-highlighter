## Maintenance fixes

- Reverting a note edit preserves a newer draft from another tab.
- Backup restore continues when the export preset list is full and reports which presets it skipped.
- Revoking GitHub access clears the update badge and stops scheduled checks.
- Older PDF renders no longer update the current view after a zoom change.

Download your browser package under **Assets**. The unsigned Firefox XPI loads as a temporary add-on. [Install and update guide](https://github.com/saeidshirazi/margin-web-highlighter/blob/main/docs/INSTALL.md)
