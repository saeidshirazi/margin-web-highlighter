## Changes

- Translate selections in Margin, including Persian, without an API key. Google detects the source language. Enable local LibreTranslate to keep translating when the shared quota is full.
- Hear selected words with automatic language detection and US or UK English voices when installed.
- Resume offline articles and PDFs. Enable reading-position sync on each browser to pick up on another device.
- Jump to matching passages from search, extract key points offline, and preview backups before restoring them.

## Install or update

Choose the download for your browser under **Assets**. Back up your library first. To update an unpacked installation, extract into the same folder and click **Reload**. The Firefox XPI is unsigned and installs temporarily.
