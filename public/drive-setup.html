Margin · Google Drive

Connect your library across devices

This development build needs a Google OAuth client before Google sign-in works. This is a one-time setup for the maintainer; users of a configured published build only click Connect Google Drive.

Edge, Brave, and Firefox

Create a Google OAuth Web application client instead of a Chrome Extension client. Copy Margin’s native callback from its Settings setup section and register it under Authorized redirect URIs. Register both browser callbacks if sharing the client. Never place a client secret in an extension. 

npm run configure:google -- --web-client-id YOUR_WEB_CLIENT_ID.apps.googleusercontent.com

Reload the original Edge installation at edge://extensions, or reload the Firefox temporary add-on at about:debugging. Firefox needs a Mozilla-signed build for permanent installation. Local features remain available without Google sign-in. The Drive API needs no billing account for this setup; do not enable paid Cloud Translation or paid storage upgrades if you want to avoid charges.

Chrome

  1. Keep your current Margin installation. Copy its extension ID from Settings or chrome://extensions. Uninstalling can remove local data.
  2. Open Google Cloud Console, create/select a project, and enable the Google Drive API.
  3. Configure Google Auth Platform branding and audience. If the app is in testing, add your Google account as a test user. Add only the https://www.googleapis.com/auth/drive.appdata scope.
  4. Create an OAuth client with application type Chrome Extension. Enter the exact extension ID as the application/item ID. Copy the client ID; no client secret is used.
  5. In the project folder, run: 
    npm run configure:google -- --client-id YOUR_CLIENT_ID.apps.googleusercontent.com
    This saves a local build setting and rebuilds Margin. For a release build, the maintainer can instead set the MARGIN_GOOGLE_CLIENT_ID environment variable.
  6. Reload the same extension in chrome://extensions. Refresh the library, open Settings & backups, read the sync consent, and click Continue with Google.

On your other devices

Use the same configured app/project and sign in to the same Google account. Published installations have a consistent extension ID. Unpacked copies on different paths can have different IDs; follow the stable-ID instructions in the project’s GOOGLE-DRIVE.md before configuring multiple development installations.

What is stored

Margin stores your saved research, settings, PDFs, and audio in its hidden application-data folder in your Google Drive. It requests access only to that folder. You will not see these files in My Drive. Your Drive storage quota applies. The local copy works offline. Margin does not add password encryption to sync files.

Changes and deletions synchronize. Conflicting edits keep a recovery copy, downloadable in Settings as JSON with the record type, source, and saved value. Pausing stops automatic sync. Disconnecting keeps both your local library and the existing Drive copy; it clears Margin’s cached sign-in tokens. Manage Google access and delete app data in your Google Drive settings.
