# Roadmap

Version 0.8 includes nested collection management and saved export presets, alongside 0.7’s backup reminders, highlight repair and first-use guidance. The current release’s implemented features are listed in [FEATURES.md](FEATURES.md). These are future improvements, not promises or shipped functionality.

- Mozilla signing for permanent Firefox installation.
- Broader live Google authorization checks outside the former test-user account and ongoing OAuth branding review if Google requests it.
- Broader real-site and accessibility testing.

Keep core highlighting, reading, local notes and exports free of accounts and subscriptions. Direct Notion API access, OCR and other services should be considered only when they improve the experience without undermining that core.
